# Employee Management System

A full-stack Employee Management System built using React, Node.js, Express, and MongoDB.

## Features

### Authentication

- Admin login
- JWT authentication
- Protected routes
- Logout

### Employee Management

- Add employees
- View employees
- Edit employee details
- Delete employees
- Search employees
- Filter employees by department

### Dashboard

- Total employee count
- Total salary
- New employees this year
- Employee list
- Employees by department

### Coming Soon

- Department management
- Reports
- Settings

## Tech Stack

### Frontend

- React.js
- React Router
- Axios
- Ant Design
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Installation

### Frontend

```bash
cd REACT
npm install
npm run dev
```

### Backend

```bash
cd EXPRESS
npm install
npm start
```

## Environment Variables

Create a `.env` file inside the `EXPRESS` folder.

```env
KEY=your_jwt_secret
PORT=3000
```
